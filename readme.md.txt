# OWASP Top 10 Practical Security Testing Project

Welcome to my **OWASP Top 10 Practical Project** repository. This project demonstrates hands-on exploitation and analysis of the most critical web application security vulnerabilities using the Damn Vulnerable Web Application (DVWA).

---

## Project Overview

This project provides detailed practical experience with vulnerabilities listed in the OWASP Top 10.  
It includes:  
- Understanding each vulnerability conceptually  
- Step-by-step exploitation using tools like Burp Suite and custom scripts  
- Evidence and analysis backed by screenshots  
- Discussion of real-world impact and mitigation strategies

---

## Vulnerabilities Covered

1. **Broken Authentication (Brute Force Attack)**  
2. **Command Injection**  
3. **Cross-Site Request Forgery (CSRF)**  
4. **File Inclusion (Local and Remote)**  
5. **File Upload Vulnerability**  
6. **Weak Session IDs**  
7. **DOM-Based Cross-Site Scripting (XSS)**  
8. **Content Security Policy (CSP) Bypass**

Each vulnerability folder contains screenshots and detailed explanations of testing methodology, payloads, and outcomes.

---

## Getting Started

### Prerequisites

- Kali Linux or any pentesting environment  
- DVWA installed locally or on a test server  
- Burp Suite Community or Professional for interception and request manipulation  
- Basic knowledge of web security concepts and HTTP protocol

### Usage

1. Clone this repository:  

 https://github.com/Jagadeesh825/owasp-top10-dvwa-practical.git

2. Review each vulnerability folder for detailed practical steps and evidence.  
3. Replicate tests in your own isolated DVWA environment for practice.
